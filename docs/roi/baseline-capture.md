## Notas de preenchimento

### Para o responsável CONDSTORE OS:

1. **Preencha em conversa, não envie formulário vazio.** O cliente pode não entender o motivo. Leia as perguntas em voz alta.

2. **Números aproximados são OK.** A meta é capturar magnitude, não precisão. Se o cliente disser "uns 15 minutos", aceite.

3. **A pergunta qualitativa é mais importante que números.** "Qual é a dor principal?" vai guiar a narrativa de sucesso ao final.

4. **Registre o custo/hora do operador discretamente.** Pergunte: "Para calcular ROI, qual é o custo hora de um operador seu? (salário + encargos ÷ 160 horas/mês)". Se não souber, use R$ 40–60 como referência.

5. **Capture fatos, não esperanças.** Se o cliente disser "a gente quer crescer 50%", anote. Mas deixe claro: o sistema não vai fazer crescer, vai liberar tempo.

6. **Termine sempre com:** "Ótimo! Agora nos próximos 30 dias, a gente volta com números reais para comparar com isso aqui. Bom?"
