# Vendas e Prospeccao - Pacote comercial executavel

Este diretorio existe para conduzir o fluxo comercial do MVP sem improviso e sem promessas fora do escopo.

Use sempre nesta ordem:

1. **Prospeccao**
   - Confirme o perfil em `icp-definition.md`
   - Use uma das mensagens curtas de `outbound-script.md`
   - Objetivo: marcar conversa com quem tem problema real e dono claro

2. **Qualificacao**
   - Rode `qualification-script.md` sem pular perguntas
   - Saida obrigatoria: `avancar` ou `descartar`
   - Se o lead pedir algo fora do MVP como condicao para comecar, descarte

3. **Demo**
   - Siga `call-structure.md`
   - Mostre apenas o fluxo do MVP: WhatsApp -> cotacao -> pedido -> visibilidade operacional
   - Se descobrir no-fit nos primeiros minutos, pare a demo e encerre a conversa com clareza

4. **Fechamento**
   - Trate travas reais em `objection-handling.md`
   - Feche o piloto com `closing-script.md`
   - Proximo passo obrigatorio: responsavel do cliente, data de kickoff e dados para onboarding

5. **Onboarding**
   - Handoff para [`../onboarding/onboarding-flow.md`](../onboarding/onboarding-flow.md)
   - Validacao operacional em [`../onboarding/onboarding-checklist.md`](../onboarding/onboarding-checklist.md)
   - O fechamento so termina quando o kickoff do onboarding estiver agendado

## Regras de uso

- Nao prometer automacao sem operador.
- Nao prometer ERP, WMS, fiscal ou marketplace.
- Nao vender "plataforma completa"; vender o fluxo operacional do MVP.
- Nao seguir para demo longa sem dor clara e sponsor identificado.
- Nao insistir em lead sem fit. Descarta rapido e segue.

## Leitura rapida por etapa

- Perfil e descarte: `icp-definition.md`
- Abordagem inicial: `outbound-script.md`
- Corte de fit: `qualification-script.md`
- Conducao da call: `call-structure.md`
- Travar objeccoes: `objection-handling.md`
- Converter para piloto: `closing-script.md`
- Cobrar resposta sem enrolacao: `follow-up.md`
